# 自动回复配置教程

个人订阅号无开发者权限，自动回复直接用公众号后台的「自动回复」功能，无需写代码。所有规则写在 `rules.json` 中，本教程教你逐条配到后台。

## 一、进入配置页

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 左侧菜单：**内容与互动 → 自动回复**
3. 右上角开启「自动回复」功能（如未开启）

## 二、被关注回复（用户关注后立即收到）

1. 点击顶部的「**被关注回复**」标签
2. 选择回复方式「**文字**」
3. 将 `rules.json` 中 `subscribe_reply.content` 的内容整段粘贴进去
4. 点击「保存」

> 提示：如果后续你建了「日报专辑」，被关注回复也可以改成「图文」类型，选择专辑，用户关注即点即看最新日报。

## 三、关键词自动回复

1. 点击顶部的「**关键词**」标签
2. 每条规则对应 `rules.json` 中的一个 `keyword_rules` 条目：

| 后台字段 | 对应 rules.json 字段 | 填写说明 |
|----------|---------------------|----------|
| 规则名 | `name` | 任意，方便自己管理 |
| 关键词 | `keywords` | 多个关键词用**竖线 `|`** 分隔粘贴，如 `日报|今日财经|财经日报` |
| 匹配方式 | `match` | `exact`=全匹配（必须完全一致），`fuzzy`=半匹配（包含即触发） |
| 回复方式 | `reply.type` | `text`=文字，`article`=图文/专辑 |
| 回复内容 | `reply.content` | 文字直接粘贴；图文则选择专辑或文章 |

3. 每条规则保存后再添加下一条，最多支持 200 条规则

### 规则优先级注意

- 同时命中多条规则时，公众号按**规则添加顺序**回复第一条命中的
- 「日报查询」这类高频词建议放在最前面
- 无关键词命中时，用户消息会走「默认回复」（可在后台单独设置）

## 四、专辑用法（强烈推荐）

关键词回复图文时只能选一篇文章，但公众号会显示该文章所属的**专辑**，用户点进专辑可看全部日报。

设置步骤：
1. 后台：**创作管理 → 专辑**
2. 新建专辑「AI 财经日报」
3. 每篇日报发布后，编辑文章 → 右上角菜单 → 加入专辑
4. 关键词「日报」的回复选择专辑链接

> 优点：回复内容永远指向最新日报，无需每周更新规则。

## 五、维护建议

- 关键词会过期：每周看看热点，把本周高频词加进规则
- 所有回复文案建议带一句「回复「日报」查看最新内容」做引导
- 不要承诺个性化回复——个人订阅号关键词回复是预设的，做不到智能问答
